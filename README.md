# TOEIC Trail

Responsive GitHub Pages entry page for the personal TOEIC learning website.

## Open the learning app

https://toeic-trail-daily-2030.sharpharp24.chatgpt.site/

The learning application remains hosted privately on Sites. Lessons, speech synthesis, quizzes, cloud progress, the vocabulary notebook, and the daily course schedule continue to use that application. This repository contains only the public entry page; it contains no learning records or credentials.

## GitHub Pages

In Settings → Pages, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

Expected portal URL after successful deployment: https://lisaou2016-lgtm.github.io/TOEIC/

The page uses relative-independent links and requires no build or package installation. `.nojekyll` enables plain static file serving.
